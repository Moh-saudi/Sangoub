# هوية السنجاب: الويب وتسليم الموبايل

## الأصول الأصلية

الحزمة المقدمة من صاحب المشروع هي `capital-talabat-logo-size-pack (2).zip`. نُسخت ملفات PNG الأصلية دون إعادة رسم أو تغيير نسب الشخصية إلى `public/brand/` بالمقاسات: 32، 64، 128، 256، 512، 1024 بكسل. أسماء الملفات `capital-talabat-mascot-logo-{size}x{size}.png`.

لوحة التعبيرات الأصلية في `docs/brand/capital-squirrel-character-sheet.png` للاسترشاد وتجهيز أصول التحريك. لا تُحمّل لوحة الشخصية الكبيرة في واجهة الزائر.

الصور المقدمة RGB بخلفيات، وليست شفافة ولا تحتوي طبقات أو ملف حركة. زر الويب يؤطر جزء الشخصية من الشعار عبر CSS فقط، دون تعديل الرسم الأصلي. لا توجد ملفات Lottie أو Rive جاهزة في هذا التسليم.

## المنفذ في الويب

- الهيدر والفوتر وبوابة الإدارة والمكونات القديمة للويب تستخدم الشعار الجديد بمقاسات مناسبة. ثوابت الواجهة المستخدمة في `src/brand.ts`.
- نافذة التطبيق تستخدم السنجاب بدل صورة الترويج القديمة، دون الادعاء بوجود رابط متجر تطبيقات لم يُعتمد.
- أيقونات المتصفح 32 و64، وأيقونة Apple 256، وأيقونات PWA 256 و512 مع أبعادها الفعلية. ليست أيقونات Android adaptive أو maskable.
- معاينة الرابط الاجتماعية تستخدم رابط HTTPS مطلقًا لصورة 1024. قد يحتفظ واتساب بمعاينة الرابط القديم لفترة؛ تعديل البيانات الوصفية لا يمسح ذاكرة واتساب تلقائيًا.
- `MascotSupport` زر يفتح قائمة خدمات: التواصل مع الدعم، طلب أوردر فطار، وطلب أوردر سوبر ماركت. الدعم والسوبر ماركت يفتحان رقم واتساب الحالي برسالة مناسبة. الفطار يفتح معالج الأصناف والكميات والبيانات والمراجعة أولًا، ثم رسالة واتساب مكتملة. لا تُرسل الرسالة تلقائيًا ولا يُنشأ طلب في قاعدة البيانات؛ التأكيد مع الفريق. القائمة تدعم الإغلاق خارجها أو بزر الإغلاق أو Escape، وتحجز التركيز داخلها وتعيده إلى السنجاب عند الإغلاق.
- الحركة افتتاحية قصيرة 2.4 ثانية لمرة واحدة عند ظهور المكون، وتفاعل قصير مع المرور والضغط. لا حركة متكررة بلا توقف. تتوقف الافتتاحية عند إخفاء الصفحة وتُلغى الحركة عند تفضيل تقليلها.
- زر السنجاب على الهاتف عائم بحجم 62 بكسل فوق شريط الطلب، حسب طلب المالك. في صفحة الوظائف، التي لا تحتوي شريط طلب، يبقى فوق الحافة الآمنة للهاتف. يختفي عند فتح نافذة التطبيق. الاسم المقروء لقارئ الشاشة يوضح أنه دعم عبر واتساب.

## المطلوب من مساعد الموبايل

لم تتغير ملفات Flutter أو Android. يستعمل المساعد ملفات الهوية أعلاه ويحدّث أيقونات التطبيق وشاشة الإطلاق حسب متطلبات Android وiOS، مع إبقاء الفاصل الآمن حول الشعار. الشعار الكامل ذو كتابة؛ يجب معاينته في الأحجام الصغيرة قبل اعتماد نسخة الأيقونة النهائية. لا يعدّ شعارًا مربعًا ذا خلفية أيقونة adaptive جاهزة.

المرحلة الأولى الممكنة بالأصول الحالية: حركات تحول خفيفة للشخصية كاملة، تشمل ظهورًا وتمايلًا محدودًا. لا يمكن فصل يد أو عين أو ذيل من ملف مسطح وكأنها طبقات حقيقية.

| الموضع | الحركة المقترحة | السلوك |
| --- | --- | --- |
| الترحيب | ظهور خفيف حتى 600 مللي ثانية | لا يؤخر الدخول أو الشبكة |
| الدعم | إطلالة قصيرة ثم سكون | يفتح واتساب، مع اسم وصول واضح |
| تحميل البيانات | مؤشر تقدم حقيقي مع السنجاب ثابتًا أو حركة اختيارية | لا يعرض تقدمًا وهميًا؛ الإعادة والإلغاء متاحان |
| السلة الفارغة | تعبير مناسب ثابت وزر تصفح | لا يحوّل حالة الفراغ إلى إعلان مزعج |
| تأكيد الطلب | حركة قصيرة بعد تأكيد الخادم فقط | لا تُظهر نجاحًا عند الفشل أو انتظار الدفع |

للتحريك التفصيلي التالي تُجهّز الشخصية بطبقات منفصلة، ثم ملف Rive أو Lottie مع أوضاع idle وgreet وsuccess. هذا عمل إضافي؛ يجب الحفاظ على تصميم الشخصية وحقوق الخطوط والشعار، واختبار الحجم واستهلاك البطارية. يحترم التطبيق إعداد تقليل الحركة ويوقف التحريك في الخلفية، وتبقى الأزرار قابلة للاستخدام دون انتظار انتهاء أي حركة.

## التحقق

اختبارات المتصفح تغطي رابط الدعم الفعلي وحجم اللمس وموضع الزر فوق شريط الطلب، واحترام تقليل الحركة، ومقاسات الهاتف والكمبيوتر. اختبار بناء PWA يتحقق من المسارات والمقاسات وذاكرة الأصول الجديدة والعمل دون شبكة بعد التحميل الأول.

## تجهيز طلب الفطار عبر السنجاب

اختيار الفطار يفتح معالجًا داخل الويب: ساندوتشات أو وجبات وكشري ← كميات ← الاسم والتوصيل وطريقة الدفع ← مراجعة ← مسودة واتساب. يمكن الجمع بين القسمين وتظل البيانات محفوظة في ذاكرة الصفحة عند الرجوع أو إغلاق القائمة، حتى إعادة تحميلها. الأصناف مقترحة وليست ربطًا تلقائيًا بمنتجات تاجر أو أسعار مؤكدة؛ الفريق يؤكد السعر والتوفر والإجمالي.

يحتوي المعالج ساندوتشات فول وطعمية وبطاطس وباذنجان وتشكيلات بيض وجبن، وكشري صغير ووسط وكبير وأطباق فطار. يقبل الأعداد الصحيحة بالأرقام العربية واللاتينية والفارسية، حتى 99 للصنف و200 إجماليًا. الاسم والعنوان واختيار كاش أو إنستا باي مطلوبة؛ المكتب والملاحظات اختياريان. إنستا باي تفضيل لطريقة الدفع، والفريق يعطي المبلغ وبيانات التحويل. لا تأكيد دفع أو سعر أو طلب خادم يُنشأ من هذا المعالج، ولا تُرسل رسالة واتساب دون أن يرسلها العميل.

تعريف الأصناف وبناء الرسالة في `src/utils/breakfastOrder.ts`، والواجهة في `src/components/BreakfastOrder.tsx`. الاختبارات تغطي طلبًا مختلطًا وإجمالي الكميات وحفظ الاختيارات عند تبديل القسم وطريقتي الدفع وبيانات العميل المطلوبة ومراجعة المسودة وفتح واتساب باعتراض محلي دون إرسال حقيقي.

## دعوة الفطار مع سنجوب

تظهر دعوة كبيرة بعنوان «اطلب فطارك مع سنجوب» بعد ثانيتين من ظهور الصفحة الرئيسية في المقدمة. تحتوي صورة الشخصية الأصلية بحركة ترحيب قصيرة لدورتين، وزر «اطلب فطارك» يفتح معالج الفطار مباشرة، وزر «هطلب بعدين» والإغلاق وEscape والضغط خارج النافذة. الحركة تُلغى مع إعداد تقليل الحركة.

تظهر مرة واحدة لكل جلسة تبويب باستخدام العلامة `capital-sangoub-breakfast-invitation-v1` في sessionStorage، مع بديل في ذاكرة الصفحة عند تعذر التخزين. تُلغى الدعوة إذا بدأ المستخدم تفاعلًا مع رابط أو زر أو نموذج، ولا تظهر فوق نافذة مفتوحة أو أثناء الكتابة، ولا تظهر في صفحة العروض أو الوظائف أو الإدارة. التصفح من الخلفية يؤجل المؤقت حتى العودة للواجهة. تُحمّل صورة الدعوة مبكرًا بأولوية منخفضة.

اختبارات المتصفح تغطي ظهور الدعوة ومقاساتها وتقليل الحركة وإغلاقها وعدم تكرارها بعد إعادة التحميل، والانتقال المباشر منها إلى الفطار. اختبار بناء PWA يغطي ظهورها في النسخة المبنية وإغلاقها قبل متابعة اختبار العمل دون شبكة.

### طلب السوبرماركت عبر سنجوب

زر «طلب أوردر سوبر ماركت» يفتح اختيار الأصناف داخل الموقع بدل رسالة فارغة: 32 اختيارًا مقترحًا في أربعة أقسام (احتياجات المكتب، الشاي والقهوة، البسكويت والسناكس، المياه والمشروبات الباردة). لكل اختيار وحدة عبوة واضحة وعدد، ويمكن الجمع بين الأقسام وإضافة أصناف أو أحجام في الملاحظات. بيانات العميل والدفع والمراجعة مشتركة مع تجربة الفطار، مع مسودة مستقلة لكل خدمة.

الأسماء والأحجام أمثلة طلب وليست كتالوج مخزون أو أسعار مؤكدة؛ لم يمكن التحقق من موقع أبو عوف الخارجي من بيئة التنفيذ. يؤكد الفريق التوفر والحجم والسعر والبدائل مع العميل. ثُمن كيلو البن = 125 جم. يختار العميل كاش أو إنستا باي، ثم يراجع رسالة واتساب ويفتحها لإرسالها بنفسه. لا ينشئ هذا المسار طلبًا في قاعدة البيانات ولا يؤكد دفعًا.
