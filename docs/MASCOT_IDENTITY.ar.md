# هوية السنجاب: الويب وتسليم الموبايل

## الأصول الأصلية

الحزمة المقدمة من صاحب المشروع هي `capital-talabat-logo-size-pack (2).zip`. نُسخت ملفات PNG الأصلية دون إعادة رسم أو تغيير نسب الشخصية إلى `public/brand/` بالمقاسات: 32، 64، 128، 256، 512، 1024 بكسل. أسماء الملفات `capital-talabat-mascot-logo-{size}x{size}.png`.

لوحة التعبيرات الأصلية في `docs/brand/capital-squirrel-character-sheet.png` للاسترشاد وتجهيز أصول التحريك. لا تُحمّل لوحة الشخصية الكبيرة في واجهة الزائر.

الصور المقدمة RGB بخلفيات، وليست شفافة ولا تحتوي طبقات أو ملف حركة. زر الويب يؤطر جزء الشخصية من الشعار عبر CSS فقط، دون تعديل الرسم الأصلي. لا توجد ملفات Lottie أو Rive جاهزة في هذا التسليم.

## المنفذ في الويب

- الهيدر والفوتر وبوابة الإدارة والمكونات القديمة للويب تستخدم الشعار الجديد بمقاسات مناسبة. ثوابت الواجهة المستخدمة في `src/brand.ts`.
- نافذة التطبيق تستخدم السنجاب بدل صورة الترويج القديمة، دون الادعاء بوجود رابط متجر تطبيقات لم يُعتمد.
- أيقونات المتصفح 32 و64، وأيقونة Apple 256، وأيقونات PWA 256 و512 مع أبعادها الفعلية. ليست أيقونات Android adaptive أو maskable.
- معاينة الرابط الاجتماعية تستخدم رابط HTTPS مطلقًا لصورة 1024. قد يحتفظ واتساب بمعاينة الرابط القديم لفترة؛ تعديل البيانات الوصفية لا يمسح ذاكرة واتساب تلقائيًا.
- `MascotSupport` رابط دعم حقيقي يفتح رقم واتساب الحالي. لا ينشئ محادثة روبوت وهمية ولا يرسل رسالة تلقائيًا.
- الحركة افتتاحية قصيرة 2.4 ثانية لمرة واحدة عند ظهور المكون، وتفاعل قصير مع المرور والضغط. لا حركة متكررة بلا توقف. تتوقف الافتتاحية عند إخفاء الصفحة وتُلغى الحركة عند تفضيل تقليلها.
- حجم الزر على الهاتف 48 بكسل داخل شريط الطلب حتى لا يغطي بطاقات المتاجر والمنتجات. في صفحة الوظائف، التي لا تحتوي شريط طلب، يبقى عائمًا. يختفي عند فتح نافذة التطبيق. الاسم المقروء لقارئ الشاشة يوضح أنه دعم عبر واتساب.

## المطلوب من مساعد الموبايل

لم تتغير ملفات Flutter أو Android. يستعمل المساعد ملفات الهوية أعلاه ويحدّث أيقونات التطبيق وشاشة الإطلاق حسب متطلبات Android وiOS، مع إبقاء الفاصل الآمن حول الشعار. الشعار الكامل ذو كتابة؛ يجب معاينته في الأحجام الصغيرة قبل اعتماد نسخة الأيقونة النهائية. لا يعدّ شعارًا مربعًا ذا خلفية أيقونة adaptive جاهزة.

المرحلة الأولى الممكنة بالأصول الحالية: حركات تحول خفيفة للشخصية كاملة، تشمل ظهورًا وتمايلًا محدودًا. لا يمكن فصل يد أو عين أو ذيل من ملف مسطح وكأنها طبقات حقيقية.

| الموضع | الحركة المقترحة | السلوك |
| --- | --- | --- |
| الترحيب | ظهور خفيف حتى 600 مللي ثانية | لا يؤخر الدخول أو الشبكة |
| الدعم | إطلالة قصيرة ثم سكون | يفتح واتساب، مع اسم وصول واضح |
| تحميل البيانات | مؤشر تقدم حقيقي مع السنجاب ثابتًا أو حركة اختيارية | لا يعرض تقدمًا وهميًا؛ الإعادة والإلغاء متاحان |
| السلة الفارغة | تعبير مناسب ثابت وزر تصفح | لا يحوّل حالة الفراغ إلى إعلان مزعج |
| تأكيد الطلب | حركة قصيرة بعد تأكيد الخادم فقط | لا تُظهر نجاحًا عند الفشل أو انتظار الدفع |

للتحريك التفصيلي التالي تُجهّز الشخصية بطبقات منفصلة، ثم ملف Rive أو Lottie مع أوضاع idle وgreet وsuccess. هذا عمل إضافي؛ يجب الحفاظ على تصميم الشخصية وحقوق الخطوط والشعار، واختبار الحجم واستهلاك البطارية. يحترم التطبيق إعداد تقليل الحركة ويوقف التحريك في الخلفية، وتبقى الأزرار قابلة للاستخدام دون انتظار انتهاء أي حركة.

## التحقق

اختبارات المتصفح تغطي رابط الدعم الفعلي وحجم اللمس وموضع الزر فوق شريط الطلب، واحترام تقليل الحركة، ومقاسات الهاتف والكمبيوتر. اختبار بناء PWA يتحقق من المسارات والمقاسات وذاكرة الأصول الجديدة والعمل دون شبكة بعد التحميل الأول.
