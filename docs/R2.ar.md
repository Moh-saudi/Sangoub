# صور الكتالوج على Cloudflare R2

الحاوية المستهدفة `capitaltalabat` في EEUR. عنوان S3 هو عنوان API للتخزين وليس رابطًا عامًا لعرض الصور. لا يلزم تغيير منطقة الحاوية أو تفعيل Workers Paid أو Event Notifications لهذا الحل. R2 له حصص وتسعير خاصان؛ لا يعني استخدامه أن التخزين غير محدود أو مجاني دائمًا.

## إعداد الحاوية الموجودة

1. من Settings → Custom Domains اربط نطاقًا للصور (مثل `images.your-domain.com` إذا كنتم تملكونه). للتجربة يمكن تفعيل Public Development URL ونسخ عنوان `https://pub-….r2.dev`؛ هذا العنوان مخصص للتطوير وله قيود خدمة.
2. هذه الحاوية مخصصة للصور العامة فقط. تفعيل عنوانها العام يتيح الوصول إلى أي ملف فيها عند معرفة رابطه، لذلك لا تضعوا بها بيانات مستخدمين أو مستندات خاصة.
3. من CORS Policy ألصق محتوى `config/r2-cors.json`. أضف نطاقكم الفعلي وأي Preview محدد عند الحاجة. لا تستخدم wildcard. CORS لا يمنح صلاحيات كتابة؛ الكتابة تحتاج توقيع الخادم.
4. أنشئ R2 API Token بصلاحية **Object Read & Write** على حاوية **capitaltalabat فقط**. لا يلزم منح إدارة الحساب أو بقية الحاويات.

## متغيرات Vercel السرية

أضف إلى إعدادات الخادم مباشرة، دون إرسالها في المحادثة أو رفعها إلى GitHub:

| المتغير | القيمة |
| --- | --- |
| `R2_ACCESS_KEY_ID` | Access Key ID الخاص بالرمز المحدد للحاوية |
| `R2_SECRET_ACCESS_KEY` | Secret Access Key الخاص به |
| `R2_PUBLIC_URL` | عنوان العرض العام HTTPS من الخطوة الأولى، دون مسار الحاوية |

لا تستخدم بادئة `VITE_` للمفاتيح. مفاتيح حساب خدمة Firebase على الخادم تظل مطلوبة للتحقق من هوية المدير وقراءة `admins/<uid>`. أعد نشر الخادم بعد حفظ الإعدادات. لم تتوفر جلسة Cloudflare/Vercel إدارية في بيئة العمل، ولذلك لم تُعدل إعدادات الحاوية أو تُنشأ مفاتيح أو تُرفع صور إنتاج.

## طريقة الرفع

يتحقق `/api/catalog-images` من Firebase ID token وتأكيد الحساب ووجود صلاحية الإدارة في Firestore. بعدها يصدر رابط PUT مؤقتًا لمدة دقيقتين لمفتاح صورة عشوائي، مع توقيع نوع الصورة وحجمها وترويسة التخزين المؤقت. يرفع المتصفح الملف مباشرة إلى R2، ثم يحفظ رابط العرض في سجل المحل أو الصنف. لا تمر ملفات الصور عبر حد حجم وظائف Vercel. عند فشل حفظ السجل يحاول العميل حذف ملفات تلك المحاولة عبر الخادم.

الأنواع المسموحة JPEG وPNG وWebP، والحجم حتى 5 ميجابايت. هذه القيود تتحقق من النوع المعلن والحجم؛ لا توجد خدمة فحص آلي لمحتوى الصورة أو إعادة ترميزها. لا يتم استيراد صور خارجية أو نسخ محتوى Google تلقائيًا. احتفظوا بالمفاتيح السرية خارج تطبيق الموبايل والويب؛ الرابط المؤقت نفسه سر قصير العمر فلا تشاركوه.

بعد الإعداد اختبروا رفع شعار وصورة صنف من حساب المدير، وظهور الصور على جهاز آخر، ورفض الرفع من حساب عميل. الاختبارات المحلية لا تؤكد اتصال الحاوية الحقيقية أو CORS أو إعداد عنوانها العام.

للتوافق مع إعدادات فرع الموبايل، يقبل الخادم أيضًا `CLOUDFLARE_R2_ACCESS_KEY_ID` و`CLOUDFLARE_R2_SECRET_ACCESS_KEY` و`CLOUDFLARE_R2_PUBLIC_URL` إذا لم تُضبط متغيرات `R2_` المقابلة. لا يمكن اشتقاق عنوان r2.dev العام من Account ID؛ انسخه من الحاوية نفسها. لا تستخدم الحاوية العامة لفواتير أو مستندات خاصة.
